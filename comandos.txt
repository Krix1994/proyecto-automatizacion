COMANDOS PARA CORRER LAS PRUEBAS - Pruebas-Dentos
====================================================

Antes de nada: abre la terminal en VS Code (Terminal > Nueva Terminal)
y asegúrate de estar parado en la carpeta "Pruebas-Dentos".


CONFIGURACIÓN INICIAL (solo la primera vez, o en un equipo nuevo)
----------------------------------------------------------------------
1. Instala esta librería adicional (lee el archivo .env):
   pip install python-dotenv

2. Crea un archivo llamado ".env" en esta misma carpeta con este
   contenido (reemplaza por tus credenciales reales si son distintas):

   DENTOS_USUARIO=tu_usuario
   DENTOS_PASSWORD=tu_clave
   DENTOS_SUCURSAL=Bucaramanga

   Este archivo NO se sube a GitHub (está en .gitignore), así que cada
   persona que use el proyecto debe crear el suyo.

CORRER LAS 13 PRUEBAS (tarda unos 9 minutos)
----------------------------------------------------------------------------
python -m pytest test_plan_tratamiento.py test_facturacion.py test_copagos.py test_cotizaciones.py -v --headed --screenshot=only-on-failure > salida.txt 2>&1

(test_plan_tratamiento.py: 3, test_facturacion.py: 3, test_copagos.py: 2 y
test_cotizaciones.py: 5.)

Cuando vuelva a aparecer "PS C:\...>", ver el resultado de cada una:
Select-String -Path salida.txt -Pattern "PASSED|FAILED|SKIPPED|ERROR|passed|failed"

Debe terminar con "13 passed".


VER UNA PRUEBA EN CÁMARA LENTA (para ver qué hace paso a paso)
----------------------------------------------------------------------------
Agregar al final del comando:   --slowmo 1000
(una pausa de 1 segundo entre cada acción) y "-s" para ver los mensajes. Ejemplo:
python -m pytest test_copagos.py -v -s --headed --slowmo 1000

CORRER SIN VER EL NAVEGADOR (más rápido)
----------------------------------------------------------
Quita "--headed" del final de cualquier comando de arriba.


SI UNA PRUEBA FALLA Y QUIERES VER EN QUÉ PANTALLA QUEDÓ ATASCADA
--------------------------------------------------------------------
Agrega al final: --screenshot=only-on-failure
Ejemplo:
python -m pytest test_plan_tratamiento.py::test_crear_anticipo_plan_tratamiento -v --headed --screenshot=only-on-failure

Luego busca la carpeta "test-results" en el Explorador de VS Code,
y abre el archivo .png más reciente.


GUARDAR EL RESULTADO EN UN ARCHIVO Y VER SOLO EL FINAL
----------------------------------------------------------------------------
Agrega al final del comando:   > salida.txt 2>&1
(la terminal no mostrará nada mientras corre; esperar a que vuelva "PS C:\...>")
Luego ver el final del resultado:
Get-Content salida.txt -Tail 8


SI LA PRUEBA FALLA EN EL LOGIN (pantalla de "Usuario / Contraseña")
----------------------------------------------------------------------------
Es un problema intermitente de entrada. conftest.py ya reintenta el
login hasta 3 veces antes de rendirse. Si aun así falla:
1. Cerrar los Chromium que hayan quedado colgados (Administrador de
   tareas: Ctrl+Shift+Esc).
2. Repetir SOLO esa prueba.
3. Si vuelve a fallar, el error trae la URL y el texto que mostraba la
   página de login: ver con
   Select-String -Path salida.txt -Pattern "Login sin completar|No se pudo iniciar sesión"


SI NECESITAS GRABAR LOS PASOS DE UNA PRUEBA NUEVA
----------------------------------------------------------
python -m playwright codegen https://release.dentos.co/auth/login

(Esto abre un navegador y va generando el código Python de cada clic
que hagas, en una ventana aparte llamada "Playwright Inspector".)
=== Flujo para subir cambios a GitHub ===

git add .
git commit -m "Descripción de lo que agregaste"
git push

=== Notas ===
- Repite esto cada vez que avances en las pruebas.
- El mensaje del commit debe describir brevemente qué cambió.
- Antes de "git add ." borrar salida.txt (es solo el resultado de una
  corrida): con "git add ." se subiría a GitHub sin necesidad.
- Para comprobar que quedó todo guardado: "git status" debe decir
  "nothing to commit, working tree clean".
